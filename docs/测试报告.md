## 3. 扫描运行验证

在本机实际运行**全盘扫描**：

- Steam 清单：`Dark Hours: Prologue`、`Don't Starve Together`、`KUNKUN Defender 2` 等。
- Epic manifest：`Botany Manor` 等。
- 自定义目录：`D:\APP2\Yslzm\LifeMakeoverGame_ob_zh_944\...\Azure-Win64-Shipping.exe`。
- 合计 8 个候选，扫描线程耗时约 10–25 秒。
- 注册表提示把该条显示为「以闪亮之名」，而不是 `LifeMakeoverGame`。
- 扫描结果均在对话框内展示，必须确认后添加。
- 过滤了卸载程序、安装器、<1MB 工具、平台启动器、微端/网页客户端、录屏/远控工具和已知辅助 exe。
- 全盘扫描默认开启；取消勾选后只扫描 Steam/Epic/常见目录。

## 4. 主题运行验证

- 深色 → 浅色：QSS、QPalette、图表、开关、卡片、原生标题栏同步变化。
- 浅色 → 深色：恢复原配色，页面仍可操作。
- 跟随系统：模拟 `AppsUseLightTheme=1` 时自动应用浅色；模拟深色时自动恢复。
- 主题选择器状态与数据库 `theme_mode` 持久化一致。
- 浅色截图：`docs/images/09-dashboard-light.png`、`10-settings-light.png`。

## 4.1 图标修复验证

- 旧版《以闪亮之名》缓存为 256×256 画布，但实际内容仅 32×32 且在左上角，卡片显示为小图。
- 新逻辑用 Windows Shell 读取真实 exe 图标，裁掉透明留白后填满 256×256。
- 用真实用户数据副本启动：2 个游戏图标被重新提取，图标文件均为 256×256，卡片显示填满图标区域。
- 旧缓存即使 exe 已丢失，也会做去留白和放大修复，不会破坏历史。
