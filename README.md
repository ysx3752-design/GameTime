# 游时 GameTime

一款 Windows 桌面游戏助手：**手动添加或按需扫描游戏、自动记录时长、卸载后不丢记录**。

游时不读取 Steam / Epic 的在线账号数据，也不会把扫描结果偷偷加入库。你可以手动选择游戏，也可以扫描 Steam、Epic 与常见 Games 文件夹，确认后再加入。游戏卸载后，名称、缓存图标与历史仍然保留。

![游时概览](docs/images/01-dashboard.png)

## 直接使用

1. 解压 `dist/GameTime-1.1.2-win64-portable.zip`
2. 运行 `GameTime.exe`
3. 点击「添加游戏」手动选择 exe，或点击「扫描游戏」从扫描结果中勾选添加
4. 启动游戏，游时会在后台自动计时；关闭主窗口会留在托盘继续记录

无需安装，无需管理员权限。数据保存在 `%LOCALAPPDATA%\GameTime`，只存储在本机。

> 这是未签名的个人软件，Windows SmartScreen 可能提示“未知发布者”。点击「更多信息 → 仍要运行」即可。

## 功能

- 两种添加方式：手动选择 exe；按需扫描 Steam / Epic / 常见 Games 目录，或全盘扫描所有本地磁盘，确认后添加
- 全盘扫描可发现 `D:\APP2\...` 这类自定义安装目录，并按注册表名称显示游戏
- 过滤微端/网页客户端、安装器和平台工具；图标读取真实 exe 并自动修复旧版小图标
- 自动检测已添加游戏的 exe 进程并计时，退出后自动保存
- 手动计时兜底，适合启动器与进程识别困难的游戏
- 深色 / 浅色 / 跟随系统三种主题，切换即时生效
- 游戏库、搜索、排序、总时长、上次游玩
- 今日 / 近 7 天 / 累计统计，14 天趋势与游戏排行
- 卸载或移动游戏后保留名称、缓存图标和完整历史，显示「文件缺失」，可重新定位
- 系统托盘、关闭到托盘、开机自启、计时通知
- CSV 导出、本地 SQLite 数据、单实例运行
- 高 DPI 支持

## 说明

- 支持 Windows 10 / 11 x64。
- 自动计时按“库中游戏 exe 的完整路径”匹配进程，不猜测、不模糊匹配。
- 自动扫描是按需触发的，结果需用户确认；全盘扫描默认开启，会遍历所有本地固定磁盘，速度较慢但能发现自定义目录。
- 扫描使用平台清单、注册表名称与路径启发式，可能把启动器/工具列为候选，建议核对后添加。
- 需要手动计时的场景：游戏由启动器拉起另一个 exe、游戏以管理员权限运行导致进程路径不可读等。
- 所有演示用游戏图标均为项目内生成的抽象图，不代表官方素材。
